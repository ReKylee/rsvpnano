# RSVP Nano v0.0.9

v0.0.9 expands device support, introduces a redesigned touch interface, adds customizable fonts and themes, improves multilingual reading, and substantially extends the companion apps.

## Interface and reading

- Redesigned the on-device interface for clearer navigation, larger touch targets, responsive layouts, and consistent behavior across narrow LCD and larger AMOLED displays.
- Added page reading with paragraph-aware scrolling alongside the existing RSVP reading mode.
- Added a chapter scroll wheel, an expanded on-screen keyboard, redesigned library cards, clearer book metadata, and improved status and settings screens.
- Added configurable left-handed layouts, reader control placement, footer metrics, battery labels, focus highlighting, text tracking, guide geometry, and reading-time estimation.
- Improved touch responsiveness for taps, holds, drags, and edge gestures while preventing transient coordinate spikes from cancelling valid taps.
- Isolated input sampling, rendering, and blocking operations so storage, network, and conversion work causes fewer visible interface stalls.
- Optimized screen updates with partial redraws where supported and reduced unnecessary full-frame flushing.

## Fonts, themes, and languages

- Added installable `.rfont4` reader fonts with large, medium, and small sizes.
- Added downloadable Andika, Atkinson Hyperlegible, Courier Prime, and OpenDyslexic families, with Literata retained as the built-in default and fallback.
- Added font catalog browsing, local font upload, installation, selection, and automatic fallback when a requested size is unavailable.
- Added versionless TOML themes loaded from the SD card, with catalog installation and local theme upload from the web and native companion apps.
- Added 12 downloadable color themes, including light, accessibility-oriented, and popular editor-inspired palettes.
- Expanded the complete on-device interface to English, Spanish, French, German, Romanian, Polish, and Russian.
- Restored accented Latin and Cyrillic rendering throughout menus and settings with a compact multilingual UI font.

## Focus, standby, and power

- Replaced fixed focus timer pages with up to six configurable focus routines containing custom names, focus duration, break duration, and round count.
- Added an animated orientation-aware hourglass interface for focus and break sessions.
- Added the Reaction screensaver and improved the performance of Life, Maze, and Voronoi screensavers.
- Added light-sleep standby, qualified touch and power-button wake handling, and automatic power-off after extended standby.
- Improved battery voltage sampling, percentage and time-remaining display, battery label controls, and battery icon visibility.

## Companion apps and device management

- Redesigned the shared Android and iOS settings and library interfaces with responsive phone and tablet layouts.
- Added live editing for reader appearance, pacing, interface, network, update, standby, focus, RSS, theme, and font settings.
- Added richer library metadata, chapter information, exact word counts, saved progress, and controls for setting a book location by chapter, slider, or word number.
- Added theme and font catalog installation, local file uploads, and active selection from the companion apps.
- Improved Wi-Fi device discovery, connection state reporting, shared network reuse, and startup synchronization.
- Added background firmware update checks on Android and build-aware update notifications.
- Added production Android and iOS app icons and updated Android support to target SDK 36.

## Storage, settings, and synchronization

- Added durable `.rstate.toml` sidecars for per-book progress and typography while ignoring stale state after a source book changes.
- Consolidated device preferences into `/config/settings.toml` with automatic defaults, cleanup of unknown fields, and a matching NVS copy.
- Added `/config/rss.toml` and `/config/focus.toml` for editable RSS feeds and focus routines.
- Added optional hardware-backed NVS encryption for device settings and Wi-Fi credentials.
- Expanded SD diagnostics to report card status and detected books, articles, fonts, themes, and configuration files.
- Improved SD setup and recovery by creating required folders when storage is available.
- Improved upload safety so existing files remain intact when a companion transfer fails.
- Improved USB mass-storage cleanup when leaving transfer mode.

## Updates and release delivery

- Added configurable startup OTA checks and release-channel pinning, including `owner/repository@tag` preview channels.
- Added build identity and commit matching so update notifications correspond to the firmware binary published in the selected release.
- Added board-specific browser-flasher images and OTA assets for every supported target.
- Improved preview publication so release metadata is updated only after replacement firmware assets finish uploading.

## Hardware support

- Added support for Waveshare ESP32-C6 Touch LCD 1.47.
- Expanded and updated support for Waveshare ESP32-S3 Touch LCD 3.49 revisions and Touch AMOLED 1.8 V1, 1.8 V2, 2.06, 2.16, and 2.41 boards.
- Corrected per-board display initialization, panel offsets, touch mapping, touch polling, SD frequency selection, power control, battery sensing, speaker enable, IMU setup, and physical button mappings.
- Improved AMOLED panel startup sequencing and fixed C6 JD9853 initialization.
- Improved LCD 3.49 touch readiness, active-contact handling, interrupt preservation, and light-sleep wake qualification.

## Reliability and compatibility fixes

- Fixed missed quick taps, delayed button activation, interrupted touch holds, and accidental menu activation during reader gestures.
- Fixed stale pixels during page scrolling and redraw identity collisions.
- Fixed localized text loss, malformed UTF-8 boundaries, and missing accent rendering.
- Improved EPUB and RSS conversion compatibility, including larger feeds, partial but complete feed items, nested navigation, encoded paths, and encrypted EPUB rejection.
- Fixed OTA version comparison, published asset matching, startup status refresh, and preview release targeting.
- Fixed audio codec detection so unavailable hardware is reported instead of being treated as initialized.
- Fixed the companion build toolchain mismatch that prevented Android and shared tests from compiling locally.
